# Packrunner frontend

React interface for route planning and delivery simulations.

1. Start [ROUTES-PROJECT-BACK](https://github.com/Franccesco1907/ROUTES-PROJECT-BACK). The API URL is configured in `src/config.js` (default: `http://localhost:8080`).
2. Run `npm install`, then `npm start`; open `http://localhost:3000`.
3. Build with `npm run build` (output: `build/`). Run the existing tests with `npm test -- --watchAll=false`.
